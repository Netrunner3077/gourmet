# Утилиты (Utils)

Вспомогательные модули, не привязанные напрямую к базе данных или интерфейсу.

## Структура

- `security.py` — хеширование паролей (Bcrypt) и их проверка.
- `validators.py` — регулярные выражения для валидации логина и пароля.
- `session.py` — класс-синглтон для хранения данных текущего авторизованного пользователя.
- `time_utils.py` — функция `utcnow()` (избавляет от DeprecationWarning в Python 3.12+).
- `image_utils.py` — обрезка изображений в круг (для аватаров), сохранение через Pillow.
- `ui_helpers.py` — добавление теней к виджетам, создание разделителей.
- `composition_analyzer.py` — парсинг текста состава, поиск E-добавок и аллергенов, расчет риска.
- `openfoodfacts_parser.py` — клиент для работы с публичным API OpenFoodFacts.
