# Слой Моделей (Models)

Этот слой отвечает за **прямое взаимодействие с базой данных MongoDB**. Модели инкапсулируют в себе все запросы к коллекциям (CRUD операции) и знают о структуре документов.

## Структура

- `database.py` — Singleton-обертка для подключения к MongoDB (создает индексы при старте).
- `user_model.py` — коллекция `users` (хеши, роли, аватары).
- `product_model.py` — коллекция `products` (характеристики, рейтинги, изображения).
- `category_model.py` — коллекция `categories` (названия категорий).
- `review_model.py` — коллекция `reviews` (тексты, оценки, лайки, вложенные комментарии).
- `cart_model.py` — коллекция `carts` (списки покупок пользователей).
- `favorite_model.py` — коллекция `favorites` (связь пользователь-товар).
- `price_history_model.py` — коллекция `price_history` (точки изменения цен).

## Правила разработки

1. Модели **не должны** содержать бизнес-логику (например, проверку прав доступа). Этим занимаются контроллеры.
2. Все методы должны использовать `ObjectId` для идентификации записей.
3. При добавлении новых полей в документы, обновляйте методы инициализации (например, `create_user`).
