# Статические ресурсы (Resources)

Здесь хранятся все статические файлы, необходимые для работы интерфейса и логики анализа.

## Структура

- `data/`
  - `additives.json` — справочник пищевых добавок (E-номера), их уровень риска и описание.
  - `allergens.json` — справочник аллергенов и их синонимов для поиска в составе.
- `images/`
  - `avatars/` — папка для сохранения аватарок пользователей (генерируется приложением).
  - `products/` — предустановленные изображения продуктов (подтягиваются в карточки товаров).
- `styles/`
  - `style.qss` — глобальная таблица стилей (CSS для PyQt5), задающая цветовую палитру и внешний вид виджетов.

## Важно

Пути к этим ресурсам вычисляются динамически в `config.py` (через `sys._MEIPASS` при сборке в `.exe`), поэтому перемещать папку `resources` без правки `config.py` нельзя.
