# Слой Контроллеров (Controllers)

Этот слой отвечает за **бизнес-логику** приложения. Контроллеры действуют как посредники между View (интерфейсом) и Model (базой данных). Они принимают запросы от пользователя, валидируют данные и вызывают соответствующие методы моделей.

## Структура

- `auth_controller.py` — регистрация, авторизация, выход из системы.
- `product_controller.py` — логика работы с товарами (оценки, избранное, корзина).
- `review_controller.py` — добавление/удаление отзывов, лайки, комментарии.
- `profile_controller.py` — управление профилем (аватар, статистика, смена пароля).
- `admin_controller.py` — CRUD операции для админа, модерация, управление пользователями.
- `cart_controller.py` — расчет суммы, обновление количества товаров в корзине.
- `compare_controller.py` — управление списком товаров для сравнения в рамках сессии.
- `price_controller.py` — обработка данных для графиков истории цен.
- `import_controller.py` — логика парсинга и импорта товаров из OpenFoodFacts.

## Правила разработки

1. Контроллеры **не должны** импортировать PyQt5 (кроме `QMessageBox` в редких случаях, лучше возвращать кортеж `(bool, str)`).
2. Контроллеры **не должны** напрямую обращаться к коллекциям MongoDB — только через методы моделей.
3. Все методы должны возвращать данные в простых форматах (dict, list, bool).
