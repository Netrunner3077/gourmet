# Слой представления (Views)

Интерфейс пользователя, написанный на **PyQt5**. Слой отвечает исключительно за отображение данных и передачу действий пользователя контроллерам.

## Структура

- `main_window.py` — главное окно (Sidebar, лента товаров, поиск, Hero-баннер).
- `login_window.py` / `register_window.py` — окна авторизации.
- `product_window.py` — детальная страница товара (состав, рейтинг, отзывы, график).
- `profile_window.py` — профиль пользователя.
- `cart_window.py` — корзина.
- `favorites_window.py` — страница избранных товаров.
- `compare_window.py` — таблица сравнения товаров.
- `admin_window.py` — панель администратора (таблицы, импорт).
- `review_widget.py` — виджет одного отзыва в списке.
- `price_chart.py` — встроенный график matplotlib.
- `widgets/` — переиспользуемые компоненты (например, `star_rating.py` — звездочки).

## Правила разработки

1. Никаких прямых запросов к базе данных (`MongoClient`). Только через контроллеры.
2. Все стили выносятся в `resources/styles/style.qss`. Не пишите инлайн-стили (кроме динамических цветов).
3. Для иконок используйте встроенные системные иконки Qt (`QStyle.SP_...`).
