# Тестирование (Tests)

В проекте используется фреймворк **Pytest** для модульного и интеграционного тестирования.

## Запуск тестов

Убедитесь, что у вас установлены зависимости для разработки:

```bash
pip install -r requirements-dev.txt
```

Запустите тесты из корневой директории:

```bash
pytest
```

Для более подробного вывода (с указанием каждого теста):

```bash
pytest -v
```

## Структура тестов

- `conftest.py` — фикстуры (создание тестовой БД `gourmet_test_db`, очистка коллекций, моки пользователей и товаров).
- `test_auth_controller.py` / `test_profile_controller.py` — тесты бизнес-логики авторизации и профиля.
- `test_*_model.py` — тесты CRUD-операций для всех коллекций.
- `test_composition_analyzer.py` — тесты парсера состава (E-добавки, аллергены).
- `test_openfoodfacts_parser.py` — тесты парсера OpenFoodFacts (с использованием `unittest.mock` для эмуляции ответов сети).
- `test_security.py` / `test_validators.py` — тесты утилит.

Всего написано 115 тестов. Все они должны проходить перед отправкой Pull Request.
