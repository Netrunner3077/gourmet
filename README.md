# Гурман — Legacy Prototype (v0.1.0)

**Внимание:** это архивная версия приложения.

Этот код представляет собой самый первый прототип приложения «Гурман», написанный в одном файле (`gourmet.py`). Прототип сохранён только для исторической справки: актуальная версия (v1.0.0+) — это полноценная переработка приложения с базой данных MongoDB и архитектурой MVC.

## Особенности этой версии:

- Весь код находится в одном файле.
- Используется база данных **SQLite** (`base.db`), а не MongoDB.
- Интерфейс создан через абсолютное позиционирование (`setGeometry`).
- Жёстко заданные (hardcoded) данные товаров и базовые категории: молочные продукты, мясо, напитки.
- Локальные отзывы по каждому товару (SQLite).
- Нет разделения на слои MVC, нет тестов и анализа состава.

## Запуск:

    ```bash
    pip install PyQt5
    cd prototype
    python gourmet.py
    ```

(Для работы требуется файл `base.db`, который лежит в этой же папке.)

## Запуск через Docker (Рекомендуемый способ)

Для запуска приложения в изолированном контейнере потребуется Docker и X-сервер (для отрисовки окна на Windows).

1. Установите [VcXsrv (XLaunch)](https://sourceforge.net/projects/vcxsrv/) и запустите его с настройками:
   - Multiple windows
   - Display number: 0
   - **Disable access control (галочка обязательна!)**
2. Убедитесь, что Docker Desktop запущен.
3. В терминале выполните:
   ```bash
   docker compose up --build
   ```
4. Окно приложения откроется на вашем рабочем столе. Для остановки нажмите `Ctrl+C` или выполните `docker compose down`.

> **Примечание:** в исходной русской версии запуск описывался как `python gourmet.py` без перехода в папку `prototype`. Файл прототипа встречается под обоими именами — используйте команду, соответствующую фактическому расположению файла в репозитории.

## Зачем он здесь?

Эта версия сохранена в отдельной ветке (`prototype`) для истории проекта. Актуальная версия (v1.0.0+) находится в ветке `main` и представляет собой полноценное приложение с базой данных MongoDB и архитектурой MVC. Дорожная карта (цель — v1.0.0: MongoDB, MVC, админ-панель и 115 тестов) доступна в ветке `develop`.
