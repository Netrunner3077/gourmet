# Гурман (Gourmet)

## Что это за проект?

**Гурман** — это десктопное приложение для оценки продуктов питания, ведения независимых отзывов и выбора качественных товаров на Python (PyQt5) с подключением к базе данных MongoDB. Приложение помогает узнать состав продукта, прочитать реальные отзывы пользователей, отследить динамику цен и получить автоматический анализ на наличие вредных добавок и аллергенов, а не полагаться на маркетинг производителей.

## Зачем он нужен?

Пользователи часто сталкиваются с проблемой: в магазине много товаров, но непонятно, какие из них действительно качественные. Приложение решает эту проблему:

- Показывает **реальные отзывы** и оценки от других покупателей.
- Проводит **автоматический анализ состава** (выявляет вредные E-добавки и аллергены).
- Отображает **графики истории цен**.
- Позволяет **сравнивать** товары по ключевым характеристикам.

## Основные возможности

- **Каталог продуктов**: Поиск, фильтрация по категориям, удобные карточки товаров.
- **Система рейтинга и отзывов**: Оценка по 5-звездочной шкале, лайки, дизлайки и комментарии к отзывам.
- **Анализ состава**: Автоматическое определение вредных пищевых добавок (E-номера) и аллергенов на основе встроенного справочника.
- **История цен**: Наглядный график изменения цен (с поддержкой выбора периода от 7 дней до всего времени).
- **Избранное и Корзина**: Сохранение понравившихся товаров и формирование списка покупок.
- **Сравнение**: Side-by-side сравнение до 4 товаров по ключевым характеристикам.
- **Личный кабинет**: Смена аватара, статистика активности, смена пароля.
- **Админ-панель**: Управление товарами, категориями, пользователями и модерация отзывов.
- **Интеграция с OpenFoodFacts**: Возможность импорта товаров по названию или штрихкоду прямо из открытой базы данных.

## Технологический стек

- **Язык**: Python 3.9+ (тестировалось на 3.15)
- **UI-фреймворк**: PyQt5
- **База данных**: MongoDB (NoSQL, документоориентированная)
- **Драйвер БД**: PyMongo
- **Безопасность**: Bcrypt (хеширование паролей)
- **Графики**: Matplotlib
- **Обработка изображений**: Pillow
- **Парсинг**: Requests, BeautifulSoup4
- **Тестирование**: Pytest (115 автотестов)

## Установка и запуск

1. Требования:
   - Установленный Python 3.9+
   - Установленный и запущенный сервер MongoDB (по умолчанию mongodb://localhost:27017/)
2. Клонирование репозитория:

   ```bash
   git clone https://github.com/Netrunner3077/gourmet.git
   cd gourmet
   ```

3. Настройка окружения:

   ```bash
   python -m venv .venv

   # Windows:
   .venv\Scripts\activate

   # Linux/Mac:
   source .venv/bin/activate
   ```

4. Дополнительная настройка окружения: скопируйте `.env.example` в `.env` (по умолчанию там локальный адрес `mongodb://localhost:27017/`).

5. Установка зависимостей:

   ```bash
   pip install -r requirements.txt
   ```

6. Наполнение базы данных (опционально):

   ```bash
   python seed.py  # Скрипт создаст базовые категории и заполнит каталог тестовыми товарами с историей цен.
   ```

7. Запуск приложения:

   ```bash
   python main.py
   ```

8. Тестирование:

   ```bash

   pip install -r requirements-dev.txt # Для запуска всех тестов (потребуется установить requirements-dev.txt)

   pytest # (Все 115 тестов должны пройти успешно).
   ```

## Как им пользоваться?

1. Зарегистрируйте нового пользователя.
2. Изучайте каталог товаров, используя поиск и фильтры по категориям.
3. Кликните на товар, чтобы увидеть его состав, рейтинг, отзывы и график цен.
4. Добавляйте товары в Избранное или Корзину.
5. **(Для администраторов):** чтобы получить доступ к админ-панели, откройте MongoDB Compass, найдите свою запись в коллекции `users` и установите поле `is_admin: true`. После перезапуска приложения в меню появится вкладка «Админ-панель».
