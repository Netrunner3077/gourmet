## [1.0.0] - 2026-10-20

### Added

- **Ядро:** Полноценная архитектура MVC (Models, Views, Controllers).
- **База данных:** Переход на MongoDB (NoSQL), создание индексов и моделей (User, Product, Category, Review, Cart, Favorite, PriceHistory).
- **Безопасность:** Регистрация и авторизация с хешированием паролей (Bcrypt), управление сессиями.
- **Интерфейс:**
  - Главное окно с боковой панелью навигации (Sidebar), поиском, фильтрацией по категориям и Hero-баннером.
  - Карточка товара: рейтинг, отзывы (лайки/дизлайки), комментарии.
  - Профиль пользователя: загрузка аватара, статистика, смена пароля.
  - Корзина и Избранное.
  - Сравнение товаров (side-by-side) по ключевым характеристикам.
- **Аналитика:** Встроенный анализатор состава (выявление E-добавок и аллергенов по JSON-справочникам).
- **Графики:** Визуализация истории цен с помощью Matplotlib (выбор периода от 7 дней).
- **Интеграции:** Модуль импорта товаров из открытой базы OpenFoodFacts (по названию или штрихкоду).
- **Админ-панель:** Управление товарами, категориями, пользователями, модерация отзывов.
- **Тестирование:** 115 автотестов (Pytest) на модели, контроллеры и парсеры.
- **UI/UX:** Кастомная тема оформления (QSS) в зеленых и синих тонах. Замена текстовых смайликов на системные иконки Qt (`QStyle`).
- **Документация:** Подробный `README.md`, а также локальные README для каждой папки проекта.

### Changed

- Полный рефакторинг и переписывание проекта с нуля по сравнению с `v0.1.0`.
- Устранены N+1 запросы к базе данных в контроллерах (batch-выборка через `$in`).
- Даты переводятся в `datetime.utcnow()` (через `utils.time_utils`) для избавления от DeprecationWarning в Python 3.12+.

### Fixed

- Синхронизация двух виджетов выставления оценки (звезд) на странице товара.
- Исправлены пути к ресурсам для корректной работы (в том числе при сборке в `.exe`).
- Защита регулярных выражений от ReDoS-инъекций (добавлен `re.escape` при поиске).

### Removed

- Удалена папка `prototype` из ветки `main` (код перенесен в отдельную ветку `prototype` через Git Worktree).

## [0.1.0] - 2026-10-20

### Added

- Первая версия приложения.
- Одиночный файл `gourmet.py`.
- База данных SQLite (`base.db`).
- Базовый интерфейс на PyQt5 (абсолютное позиционирование).
- Простая авторизация и добавление отзывов к 3 категориям товаров.
